# POWER SERVER

본 프로젝트는 PowerVision 사의 Vision+S1 어플리케이션의 로그인 api를 재구축하여 기기를 사용할 수 있도록 만드는 프로젝트입니다.

## 목차

1. Node.js 설치
2. 프로젝트 설정
3. mitmweb (mitmproxy) 설치
4. hosts 파일 수정
5. 서버 실행
6. 로그인 및 활성화

---

## 1. Node.js 설치

이 서버는 Node.js 환경에서 실행됩니다.

1. Node.js 공식 웹사이트([https://nodejs.org/](https://nodejs.org/))에 접속합니다.
2. 사용 중인 운영체제(Windows, macOS, Linux)에 맞는 LTS(Long Term Support) 버전을 다운로드하여 설치합니다.
3. 설치가 완료되면 터미널(또는 명령 프롬프트)을 열고 다음 명령어를 입력하여 정상적으로 설치되었는지 확인합니다.

```bash
node -v
npm -v

```

---

## 2. 프로젝트 설정

서버 실행에 필요한 의존성 패키지를 설치해야 합니다.

1. 터미널을 열고 `package.json` 파일이 위치한 프로젝트 폴더로 이동합니다.
2. 다음 명령어를 실행하여 필요한 모듈(`express` 등)을 설치합니다.

```bash
npm install

```

---

## 3. mitmweb (mitmproxy) 설치

네트워크 트래픽을 가로채기 위해 mitmweb(mitmproxy의 웹 인터페이스)을 설치합니다.

1. mitmproxy 공식 웹사이트([https://mitmproxy.org/)에](https://mitmproxy.org/)에) 접속하여 설치 파일을 다운로드합니다.
2. 설치가 완료되면 터미널에서 다음 명령어를 입력하여 실행할 수 있습니다.
3. 프록시 설정은 사용할 스마트폰 제조사의 사용설명서를 참고해주십시오. (대부분의 경우 PC의 IP, 8080포트입니다. )

```bash
mitmweb

```

3. 실행 후 웹 브라우저가 자동으로 열리며 [http://127.0.0.1:8081](https://www.google.com/search?q=http://127.0.0.1:8081) 주소에서 트래픽을 확인할 수 있습니다.

**참고:** mitmproxy를 사용하여 앱이 통신하는 대상 도메인 주소를 파악하는 데 활용할 수 있습니다.

---

## 4. hosts 파일 수정

특정 도메인으로 향하는 요청을 로컬 서버(이 컴퓨터)로 리다이렉트하기 위해 hosts 파일을 수정해야 합니다.


### Windows

1. 메모장을 관리자 권한으로 실행합니다. (시작 메뉴 > 메모장 우클릭 > 관리자 권한으로 실행)
2. `C:\Windows\System32\drivers\etc\hosts` 파일을 엽니다.
3. 파일의 맨 아래에 다음 내용을 추가합니다.

```text
127.0.0.1 pvmg10.sae.powervision.me

```

### macOS / Linux

1. 터미널을 엽니다.
2. 다음 명령어를 입력하여 hosts 파일을 엽니다.

```bash
sudo nano /etc/hosts

```

3. 파일의 맨 아래에 다음 내용을 추가합니다.

```text
127.0.0.1 pvmg10.sae.powervision.me

```

4. `Ctrl + O`, `Enter`를 눌러 저장하고, `Ctrl + X`를 눌러 종료합니다.

---

## 5. 서버 실행

설정이 완료되면 로컬 서버를 실행합니다. 이 서버는 80번 포트를 사용하므로 관리자 권한(sudo)이 필요할 수 있습니다.

### Windows (관리자 권한 명령 프롬프트)

```bash
node index.js

```

### macOS / Linux

```bash
sudo node index.js

```

서버가 정상적으로 실행되면 콘솔에 다음과 같은 메시지가 출력됩니다.
`서버가 80번 포트에서 실행 중입니다.`

## 6. 로그인 및 활성화
서버가 실행 중인 상태에서 앱을 통해 로그인 및 기기 활성화를 진행합니다.

1. 사용 할 기기를 블루투스를 통해 연결합니다.

2. Vison+S1 어플리케이션에 처음 진입하면 기기 이름 옆에 활성화 라는 버튼이 뜹니다.

3. 해당 버튼을 눌러서 계정 생성 화면에 진입합니다.

4. 전화번호는 임의의 번호로, 인증번호도 임의의 숫자로 입력합니다. (서버가 모든 요청에 대해 성공 응답을 보내도록 설정되어 있습니다)

5. 이용약관에 동의하고 생성을 완료하면 성공적으로 로그인 및 활성화가 완료됩니다.
